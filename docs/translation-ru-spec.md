# ТЗ: русская локализация плагина Osteon

Статус: выполнено (ветка `vibe/russian-translation-05232a`).
Объект: плагин Obsidian «Osteon» v1.4.4 (flashcards в стиле Anki).
Файлы: `src/**` (~16k строк TypeScript), `manifest.json`. Сборка: esbuild; тесты: vitest.

## 1. Цель и результат

Полный перевод интерфейса плагина на русский язык без изменения логики, форматов данных и обратной совместимости. В результате точечной правки ни одна сохранённая структура данных (json-файлы состояния, логи повторений, manifest импорта Anki, CSS-классы, ID команд) не изменилась — русифицируются только отображаемые строки.

## 2. Объём перевода (in scope)

- Все заголовки, кнопки, подписи настроек и описания (settings-таблицы).
- Notices, предупреждения, подтверждения (ConfirmModal/Confirm dialogs).
- Названия команд в палитре команд Obsidian.
- Подписи представлений (`getDisplayText`), заголовки колонок и таблиц.
- Статистика: легенды, всплывающие подсказки графиков, сводки периодов.
- Модальные окна: переноса из Spaced Repetition, фильтровальных колод, импорта экзаменов (NBME/Free 120), настроек колоды, редактора скрытия изображений и т. д.
- Системные промпты ИИ (`ASK_SYSTEM`, `EXPLAIN_SYSTEM`, `TERMS_SYSTEM`, `SPLIT_SYSTEM` в `src/plugin/ai.ts`) — переведены на русский, чтобы ответы ИИ приходили на русском (**решение согласовано с владельцем; ответ на вопрос о языке промптов не был дан, принято такое допущение**).
- Описания тем карточек, слайдеров, подсказки плейсхолдеров, aria-label.

## 3. Что не переводится (out of scope) и почему

| Группа | Примеры | Причина |
| --- | --- | --- |
| Префиксы консольных сообщений разработчика | `console.error("Flashcards: …")`, `trace("setState rendered")` | Диагностика, пользователь не видит; упрощает сопоставление багрепортов с англоязычным апстримом |
| CSS-классы и селекторы | `fc-question`, `mod-cta`, `fc-ioe-group-*` | Технические идентификаторы |
| ID команд, путей, токены поиска | `osteon-review`, `deck:…`, `is:due`, `rated:7:1`, `prop:ivl>30` | Часть синтаксиса/данных, поиск Anki-стиля не локализуется |
| Заголовки файлов данных | `# Imported Anki notes (GUID → card ID) · do not edit by hand` | Машинный формат, парсится плагином |
| Имена моделей и бренды | Claude Opus 5, AnKing, FSRS, MeSH, AMBOSS, NBME CMS, Free 120 | Собственные наименования |
| Валидные лейблы провайдеров и пресетов | preset «Default» (`DEFAULT_PRESET_ID`) | Сохраняемое значение данных, изменение сломает существующие установки |
| Пользовательские промпты-обёртки ИИ | `Card:\n${…}`, `The student's note titles:` | Внутренний формат запроса к модели; переведены только системные промпты (решение из п. 2) |
| Краткие даты `toLocaleDateString` | «Oct 1, 9:05 AM» в сводке устройств | Форматируется системными локалями устройства |
| Названия пакетов/библиотек | `@anthropic-ai/sdk`, `sql.js`, W3C URI | Технические идентификаторы |

## 5. Стиль и правила

1. **Регистр.** Кнопки и пункты меню — с заглавной буквы; описания настроек — с заглавной, полные предложения, точка в конце.
2. **Числа и плагины.** Русские формы склонений: 1 карточка / 2 карточки / 5 карточек. Используется общий хелпер `plural(n, word)` из `src/plugin/heatmap.ts` (карта `PLURAL_FORMS`), в одноразовых местах — инлайн-тернарники (`карточ${n === 1 ? "ка" : n < 5 ? "ки" : "ек"}`, `колод${users === 1 ? "ой" : "ами"}`). Латинские оставшиеся при неизвестном слове fallback `${n} ${word}${n === 1 ? "" : "s"}` — допускается только для слов, не попавших в карту.
3. **Форматирование чисел.** `toLocaleString()` сохранён; малые единицы кодируются как `мин`, `с/карточка`, `карт./день`, `повт./день`, `к/мин` — пробел после числа сохраняется.
4. **Даты.** Дни недели: Пн…Вс (порядок в карте — Вс-first, чтобы совпадал с `getUTCDay()`), месяцы: янв…дек. Полная дата — «Ср, 5 янв 2026». Часовые поясные подписи — «сегодня в HH:MM», «вчера в HH:MM».
5. **Кавычки.** Русские «ёлочки» в отображаемых строках; двойные „лапки“ исходника (`“…”`) заменены на ёлочки.
6. **Многоточие и символы.** Одиночный символ «…» сохраняется; стрелки `→`, разделители `·`, `›` сохраняются.
7. **Тире.** Для диапазонов — `–` (en dash), как в исходнике.
8. **Сохранение плейсхолдеров.** Количество и порядок `${…}`-вставок в строке должны совпадать с исходником; подстановка позиционная. Именно поэтому при переводе использовался applier с нормализацией `${}` и проверкой числа плейсхолдеров.
9. **Тон.** Обращение на «вы» со строчной; инструкции — инфинитивом или изъявительным («Пройти», «Показать ещё», «Подобрать параметры»). Безканцелярно, кратко.
10. **Точки в кнопках** не ставятся; в Notice — ставятся.

## 6. Требуемые проверки (выполнены)

- `npx tsc --noEmit --skipLibCheck` — без ошибок.
- `TZ=UTC npx vitest run` — 243 passed / 0 failed / 1 skipped (skipped — сетевой тест FSRS-оптимизатора `optimizer.real.test.ts`, ожидаемо).
- Ручная проверка остаточных английских строк (`/tmp/ru/sweep.py`) — остались только разрешённые категории из п. 3.
- Ошибочные конструкции вида `(${ })`, смешанные «вопрос ::»-строки, потерянные английские плюрализмы (`note${…:"s"}`) — исправлены в ходе аудита diff'а.

## 7. Процедура сборки артефакта Ru-дистрибутива

```bash
npm run build        # tsc --noEmit --skipLibCheck && node esbuild.config.mjs production
npm run dist         # копирует main.js, manifest.json, styles.css в dist/
cd dist && zip ../release/osteon-1.4.4-ru.zip main.js manifest.json styles.css
```

Артефакт кладётся в репозиторий по пути `release/osteon-1.4.4-ru.zip` (dist/ не коммитится).
